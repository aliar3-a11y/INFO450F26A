# INFO 450: Senior Project / Information Systems Development

**Virginia Commonwealth University** | School of Business – Department of Information Systems

---

## Course Overview

INFO 450 is a capstone course in Information Systems at VCU. This course integrates technical skills, project management methodologies, and business strategy to solve real-world problems.

Students work through the full **Software Development Life Cycle (SDLC)**—from requirements gathering and system architecture to development, testing, and deployment.

---

## Technical Stack & Tools

* **Programming / Frameworks:** *[e.g., Python, JavaScript, React, Node.js, C#, .NET]*
* **Database Management:** *[e.g., PostgreSQL, MySQL, MongoDB, SQL Server]*
* **Version Control & Collaboration:** Git, GitHub
* **Project Management:** *[e.g., Agile/Scrum, Jira, Trello, GitHub Projects]*
* **Documentation:** Markdown, Diagrams (UML, ERD)

---

## Key Objectives

1. **System Analysis & Design:** Translate real-world business requirements into technical system specifications and database schemas.
2. **Agile Methodology:** Practice iterative software development, sprint planning, and team collaboration.
3. **Full-Stack Development:** Build and deploy a scalable, functional information system.
4. **Professional Documentation:** Maintain clean code, comprehensive READMEs, and technical documentation.

---

## Key Deliverables & Projects

* **Project Proposal & Requirements Gathering:** Project charter, user stories, and feature requirements.
* **Database & System Architecture:** Entity-Relationship Diagrams (ERDs), system flowcharts, and schema design.
* **System Prototypes:** Wireframes, UI/UX designs, and functional code builds.
* **Final Presentation & Demo:** Live demonstration of the completed system and project retrospective.
